# Rotating Pentagram

## Overview
This Java program creates a graphical user interface (GUI) that displays a rotating pentagram (five-pointed star) within a circle. The pentagram rotates continuously, providing a visually appealing animation.

## Features
- Smooth rotation of the pentagram.
- Anti-aliased rendering for better visual quality.
- Customizable size and rotation speed.
- Semi-transparent fill for the pentagram.

## Requirements
- Java Development Kit (JDK) 8 or higher.
- An IDE or text editor to run Java code (e.g., IntelliJ IDEA, Eclipse, or any text editor with command line).
